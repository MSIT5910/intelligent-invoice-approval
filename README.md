# Intelligent Invoice Approval

MSIT 5910 capstone proof of concept for an AI-assisted invoice approval workflow.

## MVP Scope

The proof of concept uses:

- Exchange / Outlook test mailbox for invoice intake
- Power Automate with Copilot for invoice processing and structured data extraction
- Enterprise Service Management (ESM) for workflow, human review, coding, justification, and approval
- Human approval authority for financial decisions
- Purchasing as the downstream recipient of an approved, complete invoice record

The project intentionally uses a modular design so individual components can be enhanced or replaced as the solution evolves.

## Repository Structure

- `src/` - prototype source artifacts and implementation files
- `docs/` - requirements and technical documentation
- `design/architecture/` - editable and exported architecture artifacts
